2025 → present · Paris

Software engineer, CD platform team

The in-house platform 1,500+ Criteo engineers use to ship to production. I own features end to end across a Groovy back end, Angular and React front ends in TypeScript, C# and Python services, Concourse CI jobs and workloads on Mesos and Kubernetes.

  • My core mission is to maintain and evolve the CD system itself: the automatic deployment (autodeploy) tools, the manual deployment tool (Scala: bug fixes and new features) and the deployment configurations that describe how each service ships.

  • Built an MCP server and AI agents that answer recurring support questions, plus Slack notifications for deployment events. The engineer on duty gets interrupted far less.
  • Replaced a legacy Lua service on an ad-operations platform with an audited Django REST API, a scoped LDAP-mapped service role and full permission tests.
  • Product owner on several platform initiatives, from scoping to delivery and OKR follow-up.
  • Joined through Criteo's Big Tech-style interview loop, at the same bar as Google or Meta: data structures and algorithms, system design and behavioural rounds.
